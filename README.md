# Mechanix

An early 2D/3D game prototype in Unity. The idea is a game where every level uses a different mechanic or genre (platformer, puzzle, horror and so on). Right now only the first steps are done.

## What's done so far

- Main menu with New Game, Load Game, Options and Exit
- First level with a 2D platformer character controller:
  - Movement and jumping with Unity's new Input System
  - Shorter jump when the button is released early
  - Stronger gravity when falling, with a fall speed limit
  - Ground check and turning the character to face the movement direction
- Idle and walk animations

## Planned

- More levels, each built around a different mechanic
- Saving progress between levels

## Built with

Unity 6 · C# · Unity Input System

Art: Pixel Art Character Package and SunnyLand Artwork (Unity Asset Store)
